# Tested against Python 3.9 - 3.12.

# dash and plotly are pinned (not left loose) because Posit Connect
# resolves/caches its package environment from this file's checksum and does
# not silently re-resolve on its own - an unpinned requirement here can leave
# Connect running a dash/plotly pair installed long ago (whenever this file's
# checksum last changed), silently drifting from what's tested locally. The
# choropleth map (utils.build_choropleth_figure) uses go.Choropleth - the
# classic vector-based "geo" trace, not the MapLibre-based go.Figure -
# specifically so it never needs the browser to fetch map tiles at all,
# since this app runs behind a corporate firewall that can silently block
# that outbound traffic. Bump these pins (and redeploy) when testing against
# newer dash/plotly locally.
dash>=4.0.0
plotly>=6.0.1

gunicorn
